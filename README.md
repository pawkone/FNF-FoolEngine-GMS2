This engine **tries to mimic like "normal" FNF engines that you might know of..** (E.g. ones made in [HaxeFlixel](https://github.com/haxeflixel/flixel) like the [base game](https://github.com/FunkinCrew/funkin)), it uses:
- An "assets/" folder
- - With your normal ol' folders inside like "songs/" and "images/"
- Spritesheet Support
- - XMLs (Natively rendered in GMS2, Supports "rotate=true" and more)
- Character JSONs
- - Custom format, but based on [PsychEngine](https://github.com/ShadowMario/FNF-PsychEngine)
- OGG (Vorbis) Audio
- - Mostly since its the only supported audio type to be imported external in [GMS2](https://gamemaker.io/en)
- Chart JSONs
- - Supports pre-VSlice (Week 7 and before) charts, [PsychEngine](https://github.com/ShadowMario/FNF-PsychEngine) charts, and more!
- External GML (Soft coding) files
- - Just like LUA/.lua support in [PsychEngine](https://github.com/ShadowMario/FNF-PsychEngine) but you can make external ".gml" files and code in GML within the "songs/" folder!
